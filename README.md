# Wael's Useful Explosives

## About

This Mod Was Made so you can have many new useful abilitys and Recipes In Minecraft.

With this you can easily get to your goal faster than ever.

# Explosives

## Dirt Explosive

This is used to break **Only dirt blocks** around the player in a sphere shaped area.

It does not break the block the player is standing on as he shouldn't die.

![Dirt Explosive](https://media.forgecdn.net/attachments/description/1691444/description_71c11735-2e70-4f0b-8fb2-910f2f1188b1.png)

---

## Sponge Explosive

This is used to drain water. It is pretty useful!

It turns any water block into air in a very big range around the player.

![Sponge Explosive](https://media.forgecdn.net/attachments/description/1691444/description_45493729-1d6f-4529-b14c-fe0bfef93d97.png)

---

## Iron Ore Explosive

This can be used while mining **BUT BE CAREFUL**, as it breaks every block including diamonds.

It will only stop for **Deepslate** or **normal Iron Ores**.

![Iron Ore Explosive](https://media.forgecdn.net/attachments/description/1691444/description_fb2383a3-e4a8-42fc-8f52-0c360f2df3a3.png)
